HTTP 리디렉션과 CAPPORT는 대안입니다. DHCP option 114가 없어도 HTTP 경로로 포털을 발견할 수 있습니다.

두 경로를 글로 보기

HTTP 경로: 운영체제가 미리 아는 시험 URL로 요청 → 네트워크의 리디렉션 응답 → Location에서 포털 URL 획득 → 로그인 UI와 포털 접속.

CAPPORT 경로: DHCP option 114에서 API URI 획득 → 운영체제가 HTTPS로 상태 조회 → API JSON의 user-portal-url에서 포털 URL 획득 → 로그인 UI와 포털 접속. 별도의 push 프로토콜을 가정하지 않습니다.

제품 문서의 동작 모형이며 현장 장비를 특정한 결과가 아닙니다. example.org 계열 주소는 예시입니다.
